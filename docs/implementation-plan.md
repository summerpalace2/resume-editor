# 架构修复执行计划

目标：落实架构评审中的数据保护、保存和维护问题，保留八种版式与十六套配色。

1. 完整校验与恢复：备份及数据库共用文档解析器；成功读取才允许写回；事务内比较修订号。
2. 编辑和保存：统一修改动作、更新时间、串行防抖及显式 flush；离开页面前提交字段草稿。
3. 共用画布：提取纯文档操作、URL 和照片服务、响应式样式编排，拆分页眉、栏目、条目展示。
4. 工程约定：移除重复定义，增加 lint/格式/构建入口，固定 PDF 样本说明，同步文档。

边界：保留原数据库名称及版本；v1 备份兼容已知旧可选字段；不清空用户数据库；不更换 PDF 渲染器。
