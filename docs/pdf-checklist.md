# PDF 样本与检查约定

固定样本随项目维护，均为虚构信息：

| 文件                        | 内容                                                         |
| --------------------------- | ------------------------------------------------------------ |
| `fixtures/normal.json`      | 八种版式，各包含经历、技能和带链接项目                       |
| `fixtures/photo-large.json` | 八种版式、最大字号、占位照片；照片用于检查占位，不是人物素材 |
| `fixtures/long.json`        | 八种版式、较长标题和多页正文，含逐条内容标记                 |

这些文件都是 v1 备份，可通过“我的简历 → 导入备份”加载。建议使用单独浏览器配置或测试环境，以免样本文档混入日常简历。

## 检查路径

1. 打开一种样本版式，查看预览的栏目归属、标题、链接、字号及照片位置。
2. 点击“导出 PDF”，纸张使用 A4、边距无、缩放 100%、启用背景图形、关闭浏览器页眉页脚。
3. 正常样本检查姓名、邮箱、电话不被裁切；左右栏保持独立排列；跳转链接可点击。
4. 大字号照片样本检查姓名与照片没有重叠，侧栏加宽后正文仍在页面内。
5. 长样本检查所有内容标记均出现；栏目标题不单独留在页尾；无重复/遗漏正文或额外空白页；侧栏边缘与背景在续页保持一致。
6. 每次更改打印规则或组件 DOM，覆盖八种版式；深色和浅色配色至少各一种。
7. 记录浏览器、版本、字体环境、打印参数及样本文件，发现问题时保留 PDF 和对应截图。

## 证据边界

此前的 Windows Chrome 导出检查仍保留在外部工作目录；本轮重构没有重新运行浏览器/PDF 回归，不将旧结果当成新结构的运行时证据。

浏览器打印仍是当前导出实现。字体使用本机回退栈，不保证不同系统或浏览器的精确分页相同。关闭页面时的异步保存也不具备绝对完成保证，应以“已保存在本机”的提交状态为准。
